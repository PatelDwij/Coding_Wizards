How DocSnap Works

"AI extracts. AI checks. Humans verify. The system remembers."
We believe AI should not be blindly trusted. Here is how DocSnap provides a complete verification and audit lifecycle.

📸

1. Ingestion

Drag, drop, paste (Ctrl+V), or select multiple screenshots. Supports Timetables, Receipts, Notices, and Posters in English, Hindi, and Gujarati.

🤖

2. Vision AI

Google Gemini Flash performs one-shot OCR, document classification, schema mapping, and generates field-level confidence scores.

🛡️

3. Verification Agent

Dedicated deterministic agent audits receipt math (prices × qty = total), detects overlapping classes on timetables, and checks notice deadlines.

👤

4. Human Verification

Side-by-side split screen allows users to cross-check image pixels against extracted data. Low confidence fields are emphasized with warning badges.

🕘

5. Version History

Original AI data is never overwritten. The system records Version 1 (AI), Version 2 (User Edited), and Version 3 (Verified) with full diff tracking.

⚡

6. Smart Actions

Exports verified data into recurring weekly Google/Apple Calendar events (.ics), Excel spreadsheets (.xlsx), itemized CSVs, and interactive Q&A assistant.
